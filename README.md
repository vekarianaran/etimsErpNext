# eTIMS App

ERPNext/Frappe custom app integrating Sales Invoicing with Kenya Revenue Authority's **eTIMS** (Electronic Tax Invoice Management System).

## Installation

```bash
bench get-app etims_app <path-or-url-to-this-repo>
bench --site <site-name> install-app etims_app
```
